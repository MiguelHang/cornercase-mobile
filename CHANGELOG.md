# Changelog

Every release adds a section here for its new version. The section becomes the notes of its GitHub Release, so write it for users.

## 0.1.0

The first release: follow, answer and start cornercase's coding agents from your iPhone or Android phone. It needs cornercase 0.13.78 or later on your computer (Linux or macOS).

- **Pair with your computer.** In cornercase, open Settings › Remote › Phone app, then scan its QR code from the phone's **Machines** screen, or paste the code. Add one machine per computer, give it a name and switch between them; the app opens the last one you used.
- **See every agent on one board.** Each agent of your projects shows with its status and for how long it has been in it, the ones that need you first, and the agents they started folded under them. It updates live.
- **Talk to an agent.** Tap an agent to read its conversation and its last message as markdown, see what it is doing right now, and answer it. When it asks a question, its options show as buttons; a row of keys sends `Enter`, `Tab`, the arrows, a digit, `Esc` or `Ctrl-C`. On iPhone, attach images from your photos: they are shrunk on the phone, without their location, and reach the agent with your next message.
- **Open the live terminal.** See the agent's terminal as it runs, fitted to your phone's width, and type into it with the keys a terminal needs.
- **Start new work.** Start an agent with a prompt, in a workspace that is already open or in a new worktree, with the agent, account and model you pick. Or start an agent or a flow on an issue from any tracker cornercase is connected to.
- **Check the changes and the files.** See which files a workspace changed, read each diff and mark it viewed, as cornercase's changes panel does. Browse the workspace's files, read a file or a picture, and search them by name.
- **Close an agent.** Swipe a row left on iPhone, long-press it on Android, or tap `Close agent` on its screen; the app shows what will close and asks before closing it.
- **Try it without a computer running cornercase.** Tap `Try a demo` on the first screen, or under `Add machine` in **Machines**, to open a Demo machine simulated on the phone, marked `DEMO`, with sample agents to read, message, answer, start and close. It uses no network and saves nothing; tap `Leave demo` on the connection bar to go back.
